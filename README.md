# Mostafa Negm - Portfolio (earlier version)

## 1. Description

An earlier version of Mostafa Negm's personal portfolio website: a single-page site presenting his projects and links.

## 2. Technologies and Versions

- HTML5, CSS3, vanilla JavaScript (no build step)
- Font Awesome 6.7.2 (icons, via cdnjs)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install; an internet connection is needed for the Font Awesome CDN

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/Mostafa-Negm-Portfolio.git
cd Mostafa-Negm-Portfolio
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- Single-page portfolio (`index.html`) with styling in `style.css` and behaviour in `script.js`.
- Project cards linking to live deployments of other repositories.
